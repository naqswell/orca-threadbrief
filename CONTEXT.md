# Threadbrief

Threadbrief shows the outcome of work in Orca. The scope of a summary tells the reader whose work it describes.

## Language

**Session summary**: A structured account of the goal, completed work and remaining work for one Orca agent session. Two sessions in the same worktree can have different summaries.

**History outcome**: The selected session’s latest substantive agent reply, with up to two earlier replies for context. The panel quotes the agent; it does not generate or save a summary.

**Session checkpoint**: A numbered handoff written by the original agent when asked, then saved by the reader on the desktop. Each revision replaces the previous one for that server and session. Saving one does not launch a recap agent.

**Recap strategy**: The user's choice between reading an existing outcome and asking a separate agent for a brief recap or a detailed handoff. Selecting a strategy is not consent to send a conversation excerpt.

**Summary exclusion**: A local decision not to read or display summaries for a session, workspace or project. It does not stop the agent or erase its work.

**Worktree summary**: A shared account of work in one checkout. It can describe work beyond the active session.

**Workflow profile**: A set of rules a user chooses for their projects. It identifies where a custom workflow applies and which actions the panel offers there.

**Profile action**: A step offered by a matching workflow profile, such as preparing a push command or opening an existing review on another machine. Copying the command does not complete the step.
