How to get your first summary

Leave “Use the agent’s last reply” on. Select a local agent tab and give it a task. When the agent finishes, open this panel to read its reply. No profile or API key needed.

Want a shorter reply? Send this to your agent:

Sum up this task in my language. Use three short lines: Goal, Done, Next. Mention anything still unresolved. If nothing remains, say so.

A saved session summary takes priority. If neither source is available, the panel looks for a report shared with this worktree.
